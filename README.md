# MediDrop – Online Pharmacy App

## Project Overview

**MediDrop** is a mobile application designed to simplify online pharmacy shopping. Users can **browse, search, and buy non-medicine items, cosmetics, and baby products** from nearby pharmacies, with personalized recommendations and a smooth checkout experience.

---

## Features

* **Flutter UI**: Clean, responsive, and user-friendly interface for Android and iOS.
* **Firebase Integration**:

  * Authentication (sign-up/login)
  * Firestore database for storing products, users, and orders
* **Geolocation**: Find nearby pharmacies based on user location.
* **Cart System**: Add, remove, and manage products in a shopping cart.
* **Product Recommendations**: Personalized suggestions based on past purchases and preferences.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/MediDrop.git
cd MediDrop
```

2. Install dependencies:

```bash
flutter pub get
```

3. Configure Firebase (Authentication & Firestore) following the [official guide](https://firebase.google.com/docs/flutter/setup).

4. Run the app:

```bash
flutter run
```
